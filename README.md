# WDD 231 — Gabriel Venditti Barreira

Página pessoal do curso Desenvolvimento Frontend para Web I, construída com HTML, CSS e JavaScript sem frameworks.

## Semana 01

- Página responsiva a partir de 320 px, menu acessível e rodapé com datas dinâmicas.
- Seis cursos do array oficial, filtros por área e soma de créditos com `reduce`.
- Exercício de revisão de JavaScript em `atividades/revisao-javascript.html`.
- Os links de Câmara e Projeto Final apontam para páginas que informam em qual semana os projetos serão desenvolvidos.

## Personalização pendente

Os campos `concluido` em `scripts/cursos.js` permanecem `false` até o aluno confirmar os cursos concluídos. A existência de um projeto não comprova conclusão de um curso.

## Execução local

Na raiz: `python3 -m http.server 8000`, depois abra http://localhost:8000.
