# Semana 01 — Atividades de aprendizagem

## Convenções de nomenclatura

Arquivos em minúsculas, sem espaços ou acentos; pastas `estilos`, `imagens` e `scripts`.

## Normalização CSS

O arquivo de Nicolas Gallagher é carregado antes do CSS personalizado: em regras de mesma especificidade, a última declaração tem precedência.

## Especificidade CSS

Na demonstração do curso, as cinco cores são ordenadas assim: estilo inline `blueviolet`, ID no CSS interno `peru`, ID no CSS externo `red`, classe `forestgreen`, elemento `blue`. Os IDs têm o mesmo peso; a ordem das folhas resolve o empate. O seletor `#sub-menu .nav a:hover` tem especificidade (1, 2, 1), sem contar a coluna de estilos inline.

## Revisão de JavaScript

Abra `revisao-javascript.html`: data em pt-BR, template string, valor do input, `innerHTML` para marcação, função Celsius, `querySelectorAll` e `filter`. O CodePen de origem recusou o acesso automatizado (HTTP 403); este é um exercício local equivalente, não um fork salvo na conta CodePen.

## Cabeçalho, navegação e rodapé

A página principal implementa logo SVG, cabeçalho com Grid, botão com `aria-expanded`, navegação móvel alternável e navegação horizontal com Flexbox. Rodapé com ícones SVG, ano atual e `document.lastModified`. O SVG `teams-exercicio.svg` é o exercício de ícone em 48×48, preenchimento roxo e apenas a parte T, sem as pessoas.
